# `src/` — Kodi mbështetës për kursin *Machine Learning in Physics*

Kjo dosje përmban zbatime didaktike dhe funksione ndihmëse që përputhen me **12 temat** e kursit.

| Tema | Dosja / moduli |
|---|---|
| 1. Hyrje, të dhënat dhe validimi | `data_validation/` |
| 2. Regresioni linear | `regression/linear.py` |
| 3. Regresioni polinomial, Ridge, Lasso | `regression/regularization.py` |
| 4. Klasifikimi dhe regresioni logjistik | `classification/logistic.py` |
| 5. k-NN | `neighbors/knn.py` |
| 6. Pemët dhe metodat ansambël | `trees/impurity.py`, `trees/ensembles.py` |
| 7. SVM | `svm/margins.py` |
| 8. PCA | `pca/pca_from_scratch.py` |
| 9. Grupimi | `clustering/kmeans.py`, `clustering/hierarchical.py` |
| 10. Krahasimi i modeleve dhe pasiguria | `model_evaluation/` |
| 11. Zbritja e gradientit | `optimization/gradient_descent.py` |
| 12. Perceptroni | `perceptron/perceptron.py` |

Parimi didaktik:
**matematikë → zbatim nga parimet e para → bibliotekë standarde → krahasim → interpretim fizik**.
